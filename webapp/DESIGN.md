# 서울의 표심 — 디자인 브리프 & 결정 기록

## 1. 제품
- **무엇**: 서울 25개 자치구의 연령·가구·인구 구조와 제20대 대선 투표율·득표율을 다중 회귀로 분석한 연구발표 웹앱 (팀 양천허씨).
- **누가**: 발표 청중·심사위원(처음 보는 사람), 팀원(발표 중 조작).
- **핵심 과업**: ① 연구 질문을 한눈에 이해 → ② 세 분석 중 하나를 골라 들어감 → ③ 칸·구를 눌러 수치 확인 → ④ 한계(상관≠인과)를 읽음.

## 2. 시각 테제
"데이터 데스크의 투표용지" — 따뜻한 종이색 바탕, 흰 카드, 진한 잉크 타이포(Pretendard 800–900, 자간 −4~−5.5%).
색은 **데이터를 가리킬 때만** 쓴다: 파랑 = 이재명(진보), 빨강 = 윤석열(보수). 히트맵은 사용자 요청에 따라 음(−) 파랑 ↔ 0 회색 ↔ 양(+) 빨강(|β|가 클수록 같은 계열에서 더 진하고 선명).
브랜드 표식은 파랑|빨강으로 갈라진 막대 하나(진행 막대·로고·eyebrow에서 반복). 보라·파랑 그라데이션, 장식용 글로우, 가짜 지표는 쓰지 않는다.

## 3. 정보 구조
- `#/` 홈: 터널 히어로 → 연구 질문 + 핵심 수치 4개(카운트업) → 세 가지 분석 카드(기울기·스포트라이트) → 「우리 구는?」 탐색기(지도·목록·격차 분포 점 그림 → `#/map?sel=구`로 연결) → 분석 과정 4단계 → 결과를 읽기 전에 → 푸터.
- 분석 화면: 머리 아래 「읽는 법」 3단계, 불러오는 동안 위쪽 진행 막대, 900px 이상 내려가면 「맨 위로」.
- `#/map`, `#/household`, `#/population`: 왼쪽 사이드바(모바일은 상단 탭) + 섹션 머리(번호·질문·가장 뚜렷한 연결·새 창 보기) + 시각화 + 이전/다음.
- 해시 라우팅: 정적 호스팅에서도 새로고침·공유 링크가 동작.

## 5. 인터랙션
- **터널 히어로**(`components/ui/perspective-tunnel-hero.tsx`, 21st.dev 컴포넌트 이식): 열었을 때는 제목만 보이는 진행도 0 화면에서 멈춰 있고, 사용자가 휠·터치·키보드(↓/PageDown/Space)로 직접 움직여야 비행한다.
  끝에 닿으면 그 휠 동작은 "어디부터 볼까요?" 패널에서 멈추고, 잠깐 쉬었다 다시 굴리면 본문으로 스크롤(갇히지 않음).
  카드는 이미지가 아니라 **실제 분석 값**(미니 지도·히트맵·계수 그림·수치)이다.
- 상단 바의 섹션 링크·"분석 보기" 버튼으로 터널을 건너뛸 수 있다. 첫 Tab = "본문으로 건너뛰기".
- **액체 금속 버튼**(`components/ui/liquid-metal-button.tsx`, 21st.dev 이식, @paper-design/shaders 0.0.82): 홈 상단·터널 끝 패널·사이드바·모바일 탭·테마·새 창 보기. 링크는 `<a>`, 현재 위치는 밝은 금속 알약. 버튼마다 WebGL 컨텍스트를 하나 쓰므로 화면당 8개 이하로 유지하고, 숨긴 메뉴는 그리지 않으며(useMedia), 화면 밖·모션 줄이기에서는 정지. WebGL 이 없으면 CSS 금속 그라데이션.
- 히어로 연출: 열 때 제목이 한 줄씩 떠오름(스크롤 진행과 무관, 카드는 그대로 0) · 먼 카드는 흐리게(원근 흐림)·카드 유리 광택 · 좌우 조명이 천천히 숨 쉼 · 바깥 링 회전 · 종이 질감(히어로 전용).
- 안내 표시: 왼쪽 아래 깊이 %와 3단계(진입 / 데이터 속으로 / 분석 고르기), 오른쪽 아래 「건너뛰기」(끝 패널로 이동 → 다시 누르면 본문).
- 발표용 단축키: `0` 홈 · `1` `2` `3` 분석 · `←` `→` 이전·다음 (입력 칸·수정 키 조합에서는 무시, 시각화 iframe 안에 포커스가 있으면 동작 안 함).
- 화면 전환은 투명도·위치만 사용(filter/남는 transform 은 fixed 요소 기준을 바꾸므로 금지). 화면별 코드 분할(React.lazy).
- `prefers-reduced-motion`: 인트로·패럴랙스·휠 가로채기·등장 효과·카운트업·기울기 없음.

## 6. 시각화 연결
`viz/*.py` → `viz/*.html` → `npm run sync` → `public/viz/{map,household,population}.html`.
앱은 `?embed=1`로 iframe 삽입: 앱과 같은 종이색 배경을 직접 칠함(color-scheme 불일치로 흰 바탕이 되는 문제 방지), 시각화 내부 테마 버튼 숨김, 넓은 화면(≥900px)에서 87% 축소, 높이는 body 높이로 자동, 글꼴 Pretendard 통일.
홈의 수치·미니 그림은 `python viz/build_app_data.py` → `src/data/summary.json` (손으로 적은 숫자 없음).

## 7. 검증 체크리스트
- `npm run build` (tsc + vite) 오류 0
- 라이트/다크 × 데스크톱(1440)/모바일(390): 콘솔 오류·실패 요청·가로 넘침 0
- iframe 높이 = 문서 높이, 앱 테마 전환 → iframe data-theme 동기화
- 히트맵 칸 글자 대비 ≥ 4.5 (시각화 QA 스크립트)
